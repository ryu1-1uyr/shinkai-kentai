# 調査ノート

ゲーム設計・UX に関する調査のストック。
Web 開発の知見はあるがゲーム開発の知見が薄い、という前提で集めている。

各ノートは「調べたこと」と「**この企画（サメ培養プロジェクト）にどう当てはまるか**」の
二部構成にしてある。読み物として終わらせず、判断に使えるようにするため。

| ノート                                                | 内容                                                               |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| [01 インクリメンタルの解剖](01-incremental-design.md) | なぜ数字が増えると面白いのか。コスト式・生産式・プレステージの数学 |
| [02 ゲームの UI / UX](02-game-ux.md)                  | HUD の分類、情報設計、オンボーディングと初回体験                   |
| [03 手触り（Game Feel / Juice）](03-game-feel.md)     | 触り心地を作る三層構造と、具体的な数値レシピ                       |

## 読む順のおすすめ

1. **05（報酬と動機づけ）** — なぜ人が遊び続けるのかの土台。ここを外すと他が空回りする
2. **01（インクリメンタル）** — このジャンル固有の数学
3. **03（手触り）** — 実装に直結し、費用対効果が最も高い
4. **02（UI / UX）** — 情報設計。作り込むほど効いてくる
5. **04（事例）** — 全体を俯瞰し直すのに使う
