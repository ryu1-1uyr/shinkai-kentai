# スプライトの差し替え

ここに決められた名前で PNG を置くと、コードで手続き的に描いている仮の絵を
自動的に上書きする。**コードの変更は不要。**

ファイルが無いものはこれまで通り仮の絵のまま描かれるので、
1 枚ずつ置き換えていける。

## 画像の仕様

- **64 × 40 ピクセルの透過 PNG**
- 全レイヤーが同じ 64×40 の枠。この枠の中で位置合わせを済ませる（アンカー指定は不要）
- 体の基準位置は枠の中の **x:8〜56 / y:8〜32**（48×24）で、体の中心線は y:20
- 拡大は描画側で行うので、等倍のドット絵をそのまま置けばよい

## ファイル一覧

```
base.png                     体・ヒレ・目・口（サメの基本形）

part/tail/default.png        既定の尾びれ
part/tail/tentacle.png       触手化 — 尾をタコ足に置換
part/head/twinHead.png       双頭化 — 2 つ目の頭
part/body/mecha.png          機械化 — 胴の後ろ半分を機械に置換

attach/frenzy.png            凶暴化 — 開いた口と牙
attach/ancient.png           超古代 — 背の隆起（legendary なので見栄えを重めに）
attach/eldritch.png          古代神性 — 体表に増えた眼
attach/armor.png             装甲化 — 装甲板
attach/autonomous.png        機械兵装 — 背の砲塔
attach/alien.png             エイリアン — 触角と単眼

overlay/glow.png             発光
overlay/abyss.png            深淵種
overlay/volt.png             帯電化 — 電撃
overlay/meteor.png           隕石 — 火の粉
overlay/cosmic.png           宇宙適応 — 星空
```

**16 枚。** ファイル名は変異の内部 ID なので、表示名を変えてもファイル名は変わらない。

次の 4 種は画像を持たない（大きさや色を変えるだけで、絵そのものが無いため）。

```
巨大化      1.5 倍に拡大
ダブル      同じ絵を 2 匹に複製
高圧適応    1.12 倍 + 青灰に寄せる
飛行        傾ける + 淡く寄せる
```

色の寄せ方（どの色に何 % 寄せるか）と拡大率は
`src/render/sharkSprite.ts` の `VISUALS` に数値で書いてある。
そこだけは絵ではなく数字なので、変えたいときはコードを触る（1 行）。

## 反映のされ方

画像は必要になった時点で読みにいき、読み込めたらその瞬間に
合成済みスプライトのキャッシュを捨てて描き直す。
開発中はファイルを置いてリロードすれば反映される。

ファイルが無い間はコンソールに 404 が出るが、これは想定どおりで動作に影響しない。
